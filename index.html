Open report writing

Every task is a small program

Think like a programmer: something goes in, you process it, something comes out, and then it is tested.

  1. Input

    A source: a sentence, a talk, an article, a problem.

  2. Process

    You do the work: match, choose, highlight, take notes, write.

  3. Output

    Your paraphrase, your summary, your report.

  4. Tests

    The site runs the tests a computer can run. You run the rest.

What the site checks

  • Words copied from the source, and words you could have changed.
  • Technical terms that have gone missing, and dictionary disasters.
  • Numbers, and the small words that carry meaning: only, always, most.
  • Length and word counts.
  • The first sentence of a summary.
  • Every answer in the quick tasks.

What you check

  • Meaning: is it the same as the source?
  • Grammar: is every sentence accurate?
  • Has the grammar changed, or only the words?
  • Is a main idea missing?

A computer cannot read for meaning. So tick a test only when you have run it yourself, then swap with a partner. Programmers call that a code review.
